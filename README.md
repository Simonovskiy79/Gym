# Мой зал — дневник тренировок

Небольшое веб-приложение (PWA) для записи тренировок в спортзале. Работает в браузере телефона,
устанавливается на главный экран и работает без интернета. Данные хранятся только на устройстве.

## Возможности

- **Тренировка**: секундомер, упражнения, подходы (вес × повторы), отметка выполнения.
- Подсказка **«Прошлый»**: результат прошлой тренировки по каждому подходу. Новое упражнение
  сразу подставляет прошлые веса.
- **Кардио и планка — на время**: вместо веса и повторов вводятся минуты и секунды.
  Тип («вес и повторы» или «только время») задаётся у каждого упражнения.
- Заполненные подходы засчитываются при завершении, даже если не нажата ✓.
- **Таймер отдыха**: запускается после отметки подхода, по окончании вибрирует и подаёт звук.
- **Шаблоны**: завершённую тренировку можно сохранить и начинать следующую в одно касание.
- **История** по месяцам: длительность, объём, детали. Тренировку можно повторить или удалить.
- **Прогресс**: тренировок за неделю и месяц, график расчётного максимума на 1 повтор (формула Эпли), рекорды.
- **Фото тренажёра** у каждого упражнения: снять можно прямо в зале кнопкой 📷 в карточке
  упражнения. Фото сжимается примерно до 100 КБ и хранится в IndexedDB.
- **Видео техники** (кнопка ▶ у упражнения): ссылка на YouTube проигрывается прямо в приложении,
  есть кнопка «Найти на YouTube». Можно прикрепить своё видео (до 150 МБ): оно хранится на телефоне
  и в резервную копию не входит.
- **Справочник упражнений** по группам мышц: можно добавлять свои.
- **Резервная копия**: экспорт и импорт JSON вместе с фото (⚙︎ → Данные). Там же видно состояние
  хранилища. Данные дублируются в localStorage и IndexedDB, приложение просит браузер не очищать их.

## Вкладка «Claude»

Связь с Claude без сервера и API-ключей, через копирование текста:

1. **О вас**: цель, опыт, сколько раз в неделю, ограничения. Попадает во все запросы.
2. **Разбор тренировок**: приложение собирает статистику за 4 недели, 3 месяца или всё время
   (сводка, прогресс по упражнениям, дневник) с готовым запросом. Кнопка «Скопировать и открыть Claude».
3. **Составить или обновить план**: запрос, в котором Claude просят ответить JSON-блоком в формате приложения.
4. **Загрузить план**: вставить ответ Claude. Приложение найдёт JSON, покажет предпросмотр и создаст
   тренировочные дни (шаблоны с меткой «План») с целевыми подходами, повторами, весом и отдыхом. Недостающие упражнения добавятся.

Во время тренировки по плану цель видна под названием упражнения, а вес и повторы подсказаны серым.
✓ принимает подсказку, таймер отдыха берёт время из плана.

## Запуск

Сборка не нужна, это обычные статические файлы.

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

### На телефоне

Проще всего включить **GitHub Pages**: Settings → Pages → Deploy from a branch → выбрать ветку, папка `/ (root)`.
Затем открыть полученный адрес на телефоне и выбрать «Добавить на главный экран»
(Safari → Поделиться, Chrome → меню ⋮).

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка и нижние вкладки |
| `styles.css` | стили (светлая и тёмная темы) |
| `app.js` | основная логика и хранение (`localStorage` + копия в IndexedDB) |
| `claude.js` | вкладка «Claude»: выгрузка статистики, запрос и загрузка плана |
| `sw.js` | service worker для офлайн-режима |
| `manifest.webmanifest`, `icon.svg` | установка как приложение |
