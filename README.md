# Мой зал — дневник тренировок

Небольшое веб-приложение (PWA) для записи тренировок в спортзале. Работает в браузере телефона,
устанавливается на главный экран и работает без интернета. Данные хранятся только на устройстве.

## Возможности

- **Тренировка**: секундомер, упражнения, подходы (вес × повторы), отметка выполнения.
- Подсказка **«Прошлый»**: результат прошлой тренировки по каждому подходу. Новое упражнение
  сразу подставляет прошлые веса.
- **Таймер отдыха**: запускается после отметки подхода, по окончании вибрирует и подаёт звук.
- **Шаблоны**: завершённую тренировку можно сохранить и начинать следующую в одно касание.
- **История** по месяцам: длительность, объём, детали. Тренировку можно повторить или удалить.
- **Прогресс**: тренировок за неделю и месяц, график расчётного максимума на 1 повтор (формула Эпли), рекорды.
- **Фото тренажёра** у каждого упражнения: снять можно прямо в зале кнопкой 📷 в карточке
  упражнения. Фото сжимается примерно до 100 КБ и хранится в IndexedDB.
- **Справочник упражнений** по группам мышц: можно добавлять свои.
- **Резервная копия**: экспорт и импорт JSON вместе с фото (⚙︎ → Данные).

## Запуск

Сборка не нужна, это обычные статические файлы.

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

### На телефоне

Проще всего включить **GitHub Pages**: Settings → Pages → Deploy from a branch → выбрать ветку, папка `/ (root)`.
Затем открыть полученный адрес на телефоне и выбрать «Добавить на главный экран»
(Safari → Поделиться, Chrome → меню ⋮).

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка и нижние вкладки |
| `styles.css` | стили (светлая и тёмная темы) |
| `app.js` | вся логика и хранение в `localStorage` |
| `sw.js` | service worker для офлайн-режима |
| `manifest.webmanifest`, `icon.svg` | установка как приложение |
